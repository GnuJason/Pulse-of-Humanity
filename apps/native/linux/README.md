# Linux Screensaver Placeholder

Linux packaging is intentionally a placeholder while the project chooses a supported host integration. `run-screensaver.sh` opens the built offline web runtime, and `pulse-of-humanity.xml` is an XScreenSaver module stub.

Before packaging, select and implement one supported path: XScreenSaver, GNOME Shell, KDE Plasma, or a dedicated GTK/WebKit host. This directory must then gain installation, preview, and host-lifecycle smoke tests.
